## What this repository holds (high level)

* **Notebooks/** — Interactive Jupyter notebooks that walk through concepts, experiments, and demonstrations. Each notebook contains explanations, code cells, and observed outputs.
* **projects/** — Complete end-to-end projects and mini-systems built to apply AIOps concepts (monitoring automation, CI/CD pipelines, alerting, anomaly detection, infra automation, etc.).
* **scripts/** — Reusable Python and shell scripts used across projects and experiments.
* **infra/** — Infrastructure-as-code examples (Terraform, CloudFormation snippets, or manifest files for Kubernetes), Dockerfiles, and environment setup scripts.
* **configs/** — Example configurations for Prometheus, Grafana dashboards, Logstash/Fluentd, and other observability tools.
* **dashboards/** — JSON/exports of dashboards (Grafana) or notebook visual outputs demonstrating metrics and traces.
* **data/** — Small example datasets used for experiments. (Large or licensed datasets are referenced with instructions to download separately.)
* **docs/** — Write-ups, architecture diagrams, and reflective notes for each major topic.
* **README.md** — (You are reading it.) Overview and usage instructions.
