Unicode Characters:
for uniode characters use backslash and u
text = "\u00A9" 
print(text)


# for 8 digit hexa decimal number(emojis)
text = "\U0001F600"
print(text)

Bell:
will hear a bell sound
text = "Hello\aWordl"


Octal and Hexadecimal
text = "Hex: \x41"
print(text)

Raw Strings
r in raw string literals treat backslashes as literal characters not as escape characters
text = r"C:\Program Files\SomeFolder"
