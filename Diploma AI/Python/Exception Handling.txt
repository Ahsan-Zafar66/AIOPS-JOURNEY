Example of exception handling
try:
  with open("ahsan.txt","r") as file:
    for line in file.readlines():
      print(line)
except FileNotFoundError:
  print("file not found")

else:
  print("The exception is not handeled")

---------------------------------------------

# writing multiple exceptions at once
try:
  print(10/0)
except (FileNotFoundError,ZeroDivisionError):
  print("file not found or zero division erro")

else:
  print("The exception is handeled")

when try statement is executed and else will run simultaneously

when error raised statement in the except  clause will run

# finally clause will run whatever happens whether try statemnet runs or not, finally will be excuted at all cost
# you can use finally clause with try clause only. You cannot use try, except and finally clause at once.
