AD connect:
AD connect is a AWS service which allows you to connect with your active directory the one intelliverse.ai we created in london region ec2 server
AD connector is a dual availability zone proxy servie that connects AWS (ohio) to you on-premises directory (london)
With AD connector, you can streamline identity management. You will create account in london and you can connect with ohio using AD connector, no need to create users on both london and ohio.

Now, the thing is we will create user in london region and using this user we will enter the ohio region server through one user. This is called single sign on
Go to active directories users and computers, and go to your AD which is intelliverse.ai, got to users and create a user in london region AD
