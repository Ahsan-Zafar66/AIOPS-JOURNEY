Auto Scaling is a feature of AWS. It is 100% free because it is a feature not a service.
Autoscaling is a feature that allows your AWS compute need (EC2 instances fleet) to grow or shrink depending on your workload requirements

AutoScaling helps you save costs by cutting down the number of EC2 instances when not needed and scaling out to add more instances only when it is required



How autoscaling works? WHich ec2 instances are added?
When we set autoscaling we define ec2 instance parameters to add such as their family, instance type, AMI, key pair, block devices, security groups and etc. 
These things are defined in advance so when AWS needs to add instances it knows which instance with which properties to add

We need to give a custom AMI image, from which AWS will make new instances.

Scaling Policy:
It determines the limit after which AWS will add new instances or remove instances to scale down.

Suppose you mentioned 50%, it means your desired instances load average is 50% than it will add number of instances until it reaches maximum number of instances.

For example:
Policy load : average 50% of minimum instances

Desired = 2

Minimum : 2

Maximum = 4


NOw, as minmum instances set is 2, if their average load increases 50% then ASG will launch 2 more instances as maximum can be four. When the average load of 4 instances gets lower then 50%, it will terminate the instances.
