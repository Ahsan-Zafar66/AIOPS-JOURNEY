what is configuration?
In simple words, configuration is installation of packages to configure the machine to run the services needed.

What is Shell Provision?
Installing softwares automatically by configuring the Vagrantfile

Go to the vagrant file in botom you will see config.vm.provision "shell"

uncomment the above line and write the package you want to instal in next line

# complete syntax for installing git through shell provision is in bottom of vagrantfile


# you can install multiple packages at once by writing them alon each other


Recommended way.
We make a file and define packages in it
and run this file

# code and syntax
$myscript = <<-"MYABD"
  apt-get remove -y git
  echo "Ahsan Zafar" >> /home/vagrant/ahsan.txt
  MYABD

  config.vm.provision "shell",
    inline: $myscript


above i am creating a script call myscript and saving it in a variable

then i am writing my lines or script like removing git and making a text file in path /home/vagrant/ahsan.txt and writing something in it

then i am using shell in vm and calling the mysscript and running it
