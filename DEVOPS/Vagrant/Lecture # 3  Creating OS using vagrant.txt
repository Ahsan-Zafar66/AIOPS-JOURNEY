Install vagrant on windows and reboot your machine

Now, go to vagrant cloud and chose a avagrant box, vagrant box are like docker images

# now download the vagrantfile of that vagrant box in your directory by running the command vagrant init vagrant_boxname

# now run vagrant up command in the directory where vagrant file has been downloaded

# command to check vagrant machine status
vagrant status

# now check your virtual box, you will see an OS running whcih you downloaded

# run following command to take vagrant machine console
vagrant ssh

# when machine is up by default it has username and password
SSH username: vagrant

default password: vagrant

#  now move out of vagrant os by using exit command
exit

# vagrant suspend command save the machine state
vagrant suspend

# now to start again use vagrant up command
vagrant up

# to power off vm use vagrant halt
vagrant halt

# to destroy or remove vm use
vagrant destroy
