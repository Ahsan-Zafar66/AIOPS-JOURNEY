# How to edit an original Workflow?

Step # 1
Create a copy of this workflow. Now, this copy will be available in inactive workflows

Step # 2
Go to workflow schemas, find your project and change the workflow from the original to the copy one, publish it 

Step # 3
The step 2 will put the copy workflow schema in active schemas and original schema in the inactive schemas

Step # 4
Now, edit the original workflow schema which will be in inactive schema as you like

Step # 5
Now, go to workflow schemas, find your project replace the copied schema with the orignal schema containing your desired changes and publish it


Step # 6
Now, your copy workflow schema will be in inactive schemas and original modifed one in the active schema.
