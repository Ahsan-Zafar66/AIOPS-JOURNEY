Step # 4 Linking github repository with jenkins

Now, log into jenkins and click on creating a job
Chose pipeline or freestyle project as you like.

Now, go to github repository you want to link, go to its settings and then go to webhook. Paste the link of jenkins server here.
jenkins-link/github-webhook/

Now, create this webhook, if github can access the jenkins server it will show successfull sign else it wil show unsuccessfule sign

Now, copy the repository link by going in that repository and paste it in jenkins job in github project box/section
Now, in source code management section in jenkins, select git and paste the git link, by going in github repository click on green code icon you will get git link there.
Now, make sure what is your branch of repository is it master, main, brach1 or whatever make sure you enter correct name here
Now in trigger section select "GitHub hook trigger for GITScm polling"
