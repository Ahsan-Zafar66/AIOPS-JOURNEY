Chef is an configuration management tool.
Configuration of machines is of two types:
1) Push based, in this type updates are pushed to worker nodes through a server. Forexample ansible or salt stack
2) Pull based, in this type updates come in server and each node attach to server pull updates to itself. For examle cheff or puppet


Cheff is mage in Ruby or Erlang language
Adam Jacob made cheff in 2009

What is infrastructure as code?
Infrastructure ko build krna code ki madad sy. For example ansible, salt, puppet, chef
