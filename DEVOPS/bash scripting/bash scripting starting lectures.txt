Shebang (#!):

The #! sequence is interpreted by the Unix/Linux kernel when executing files. It indicates that the file should be executed using the interpreter specified after the #!.
Interpreter (/bin/bash):

Following #!, /bin/bash specifies the path to the Bash interpreter (bash shell) on the system. In this case, /bin/bash is the full path to the Bash shell executable.
Purpose:

When you run a script file that starts with #!/bin/bash, the system knows to use /bin/bash to interpret and execute the commands in the script.
This line essentially tells the operating system that the script should be executed using the Bash shell, ensuring compatibility and correct execution of Bash commands within the script.

# a script to check if a serive or software is installed and what it's version"

#!/bin/bash

echo "Enter the name of service whoe version you want to check"

read service

command=$(which $service)

status=$(echo $?)

if [[ status -eq 0 ]]
then
	echo "Program ran succesfully"
	echo "Version of service is: $($service -v)"

else
	echo "Service not installed"

fi
