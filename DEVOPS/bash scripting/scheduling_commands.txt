crontab guru website


Crontab syntax:-
MIN HOUR DOM MON DOW CMD

Field    Description    Allowed Value
MIN      Minute field    0 to 59
HOUR     Hour field      0 to 23
DOM      Day of Month    1-31
MON      Month field     1-12
DOW      Day Of Week     0-6
CMD      Command         Any command to be executed.


crontab -e --> to do entry in crontab

* * * * * echo $(date) >> /var/ahsan/txt --> after every minute add the command output to data to ahsan.txt

crontab -l --> to see the crontab tasks.

crontab -r --> to remove all the schedule processes, in short clear the file.
