OWNERS:

chown newowner filename --> changing the owner of a file.

sudo chown -R ownername filename --> changing the owner of file to new owner directly without going to root user.

chgrp groupname filename --> changing the group of the file.

sudo chgrp -R newgroupname filename --> changing the group of the file without going to root user.

chmod u+x filename --> To give full privileges of a file to a user. read, write, executable.

chmod g+x filename --> To give full privileges of a file to a group

chmod o+x filename --> to give full privileges of a file to everyone.

chmod u+x,g+x,o+x filename --> To give privileges of a file to group and everyone and once.

chmod u-x,g-x,o-x filename --> Taking away all the privileges.
