Interview related question.

How to read a file in bash scripting

Method # 1
file="names.txt"

while read line
do
	echo "$line"
done < $file

Method # 2

cat names.txt | while read line
do
	echo "$line"
done

=====================
How to take output of a command line by line?

ls -ltrh | while read line
do
	echo "$line"
done
