docker networking:
when we install docker, a lot of libraries are installed with it.

docker network model is CNM, container networking model.

When a container is made from an image it comunicates with CNM through Docker engine, which uses libnetwork to communicate with CNM.
container ---> DE --> Libnetwork ---> CNM


There are two libraries that is used by docker engine to make the network layer.
they are network driver and IPAM driver.
IPAM driver act as dhcp, which has two jobs, one to create a pool of ip addresses and second one is to assign the ip addresses

network driver has the job of network creation, attaching a container, removing a container from network.

Network sandobox does the routing between containers, it also does ip management
