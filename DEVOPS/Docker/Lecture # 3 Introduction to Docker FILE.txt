In docker we have two images especially for docker
1) BusyBox: for print statements such as docker run hello-world
2) Alpine image: web server, python, java, mysql, promethis and nagios etc

What is difference between other OS and alpine image?
in industry where there are thousands of server, and normal OS have size ranges from 10-30GB, now for each server 10-30GB space is used by os and then comes services size
Alpine image is very lightweight image of like 50MB and then other services are installed. So, in this way space is saved.
