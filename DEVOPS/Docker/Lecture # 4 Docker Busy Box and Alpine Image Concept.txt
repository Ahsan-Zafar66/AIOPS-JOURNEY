# removing a docker image
docker rmi image_id

# removing a container
docker rm container_id

if we want to remove a docker image, first we need to clear it's docker container.


# going into interactive terminal in busybox
docker run -it --name CONTAINER1 busybox /bin/sh

by running above command you will enter a terminal /bin/sh in busybox, you can do all the things in that terminal. You can create new files delete and much more. These files or changes will be inside the busybox container. Changes made inside busybox will not effect base machine, everything will be for busybox


#we have docker image and we run it in container, once process stopped container is stopped. So, in order to run image again we can use
