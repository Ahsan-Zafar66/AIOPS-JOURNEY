Local repository:
Like we store our images in docker hub we push and pull images from there.
Local repository means creating a docker repository in your local system for storing images which you can pull later

# following is the command creating a docker repository names registry, the repository is actually a container running to act as a local repository
docker run -d -p 5000:5000 --restart=always --name registry registry:2

docker run --> to run a container from an image

-d --> detached mode, do not show any output of the command

-p --> port mapping, 5000 of host is mapped with 5000 of container

--restart=always --> if container crash or stops restart it, it is for HA

--name registry --> setting container name will be registry

registry:2 --> it is the image and it's tag


# now a contianer has been created named registry

How to push an image in local repository now?
# step # 1 tag the iamge
docker tag alpine localhost:5000/alpine

# now push the image
docker push localhost:5000/alpine

# now take the console of container
docker exec -it registry /bin/sh

# now find the image
find / -name alpine --> this command will give you the path where your image has been stored in container which is acting as local repository
