This lecture is dedicated for docker path change

Mostly comes a requirement that we need to store data on a path other then default docke rpath which is /var/lib/docker/

SO this thing is very important

How to Change Docker Default Path?

Step # 1
Create a directory name docker in the location where you want to create new path

# for example
mkdir /home/docker

# new path is /home/docker

Step # 2
Stop the docker service and docker socket using following commands
systemctl stop docker.service

systemctl stop docker.socket


# Step # 3
Create a file using following command in /etc/docker/ path
vim /etc/docker/daemon.json

# in this file write the new path of docker
{
	"data-root": "/home/docker"

}


Step # 4 
Now copy everything from the previous path to new path using folowing command

cp -axT /var/lib/docker/ /home/docker/

Step # 5
Now open the docker service file and add your new path to it
vim /lib/systemd/system/docker.service

And add the new path in the following line

Before adding path:
ExecStart=/usr/bin/dockerd -H fd:// --containerd=/run/containerd/containerd.sock

After adding path
ExecStart=/usr/bin/dockerd -H fd:// -g /home/docker --containerd=/run/containerd/containerd.sock

step # 6
reload daemon process using following command
systemctl daemon-reload

# now start the docker service
systemctl start docker.service

systemctl start docker.socket

# now run docker as you want
