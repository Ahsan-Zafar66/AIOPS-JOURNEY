Docker Architecture:
1) Docker Server
2) Docker Client 
3) Registry --> Storage/Directory 

Docker Server:
Docker install  --> Docker server --> work as a daemon/process, for example CentOS. Daemon means process will run in background

Docker Client:
It is for user docker commands and it will communicate with docker server. You write commands in client and it sends to server.

Registry:
Docker/DotCloud introduce docker files. We need to store files in a docker image. registry is public directory and anyone can use it

Container:

Docker File build --> Docker Image run --> Docker Container

We make a docker file do configurations install dependencies all thins our application need, then we create a docker image and when we run the docker image it is called container as all the things that are required by my application are inside a container
