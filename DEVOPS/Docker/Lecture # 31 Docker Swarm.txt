Docker swarm is an orchestration tool, it manages multiple container and its job is high availability

Docker swarm is not widely used as it is being replaced by AWS and kubernetes



Docker swarm is a cluster which consist of master and worker nodes.

Master node : ip of machine which you want to make master node

# following is the command to make a machine master node
docker swarm init --advertise-addr 192.168.1.8

# the output of above command is important copy them, as it contains the command to make the worker nodes

# command to see details of a cluster, run this command in master machine
docker node ls

# create a custom overlay network in master machine
docker network create --driver overlay mynetwork

# now when we want to create a container in docker swarm, we need to use service create
docker service create --name mycontainer -d --network mynetwork -p 8001:80 busybox

# seeing the list of containers running in docker swarm
docker service ls


# NOTE: the container process should be long running to see them, if it is short running you won't see it 

# to shutdown a service in a node
# get the id of service and see the name of nodes in which it is running
docker node update --availability drain node_name

# for example
docker node update --availability drain ahsan

above command will shutdown all the services running in node ahsan

# now to make the ahsan active
docker node update --availability active ahsan


# removing services
docker service rm service_name


the node which is down, service on its ip address will also be down

# command to leave the cluster or swarm
docker swarm leave

the worker node will left the swarm

# removnga node
docker node rm node_name

# chekcing logs of a service
docker service logs service_ID
