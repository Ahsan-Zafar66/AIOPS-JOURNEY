Docker secret:
it works only with docker swarm. it makes transmission of data between nodes secure.

Suppose you have a docker swarm cluster.
It has a master node and many worker nodes.
Docker secret stores all the passwords in manager which are encrypted.
So, when a node needs a password it gets from the master. The password transmission from master to worker node is very secure.
manager has password in harddisk and node has in memory, when the worker node die the password will be vanished as it was stored in memory not hardisk

Communication between master and worker node is done through TLS and C-A


# how to create a secret with a standard input like you pass input while creating a secret
echo "password: 123456789" | docker secret create my_secret_password -

so breakdowning above command:
echo "password: 123456789" --> this is my content mean my secret to store

docker secret create --> it is the command to create the secret

my_secret_password --> this is the name of my secret

- --> it means take the input of echo command the content which is my secret to protect

# so how to access this secret in a container?
So, what happens, when we need to use this secret in a container we mention the secret and secret name while creating the container.
So, what docker do, it creates a file in that container, the file name is the secret name and content is the secret we mentioned while creating the secret.
So, now docker container can use the secret from the file created on the name of secret.

# for example
docker service create -d --name mycontainer --secret my_secret_password nginx

So, in above container whose name is mycontainer, a file will be created name my_secret_password and this file will contain contents of secret


# now in take the console of above container
docker exec -it mycontainer /bin/bash

# now the secret file will be created in path /run/secrets/<secret_name>
cd /run/secrets

you will see a my_secret_password file here and it's content will be what you passed in echo



# command to see that service is running on whch node
docker service ps service_id


# if you want to remove the secret file or data from a container, you can do it from master node
docker service update --secret-rm secret_name service_name

remember we remove secret data from service not from container, when we remove from service it get remove from container automatically

# example
docker service update --secret-rm secret_password myservice


# command to remove secret from docker
docker secret rm secret_name

docker secret rm secret_password
