Steps to create a docker file
1) Create a directory and enter in it

2) create a DockerFile using "vim Dockerfile" command

3) Now after opening the file write things you want to do when you run this image

For example
# use the alpine os
FROM alpine

# install the python
RUN apt-get install python

# show current working directory
RUN echo $(pwd)

# create a file
RUN touch fileindocker.txt


4) create image of docker file

docker build -t firstimage . --> firstimage is name of image that is to be created. "." is used to capture the docker file in the directory


# creating versions of an image
docker build -t firstimage:v1 .

# second version of same file
docker build -t firstimage:v2 .


# now when you are running the image you must specify the version
docker run -it firstimage:v1 /bin/sh --> interactive terminal of firstimage v1

# to run v2
docker run -it firstimage:v2 /bin/sh

# Concept of docker image, container and exec command
docker run image --> command run image and create the container

# starting a exited container
docker container start container_id

# now running commands on a started container without entering it's shell
docker container exec container_id command 



# to show the output of a container using in start command
docker start container_id --attach


# using detach command to run process in background
docker run -dit alpine /bin/sh --> run /bin/sh shell in backgroup. d means detach
