# command to stop docker
systemctl stop docker.socket

# now you run docker ps or docker images commands will not work

cd /var/run in this directory there is docker.sock file.

docker socket file connects docker client with docker server.

if docker is corrupted and it is not working, we kill or remove the docker.sock file.
now you run docker again and docker.sock file is again created


# starting docker socket file
systemctl start docker.socket


# check status of docker socket
systemctl status docker.socket


What is Port Mapping?
port mapping is mapping port with another port.
For example apache uses 80 port, we are using apache in container.
So, I map 8080 with 80 port. Now, anyone from outside who wants to interact with port 80 will not write 80 he will write 8080, this 8080 will interact with port 80.

So, port maping is nothing but mapping ports with othe rports for outside communication,

In this way people don't interact directly with port 80, they interact with port 8080

# running nginx and mapping port 80 with 9000
docker run -it -d -p 9000:80 --name mywebserver nginx:latest

# now you can connect with above server using command
curl http://localhost:9000

# you can check this port mapping using following command
netstat -tulnp

you can write exit to stop the server
# starting mywebserver again
docker start --attach mywebserver

-d --> Detach mode
-a is called attach -->
