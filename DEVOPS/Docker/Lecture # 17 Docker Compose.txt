Docker Compose:
Docker Compose is an advance type of Docker file.
We use to run containers from images each time a container stops

Rather then defining container from an image we can define a container in a Docker Compose file and can run it

# location os this practical in ubuntu is /docker_compose

# requirements
package.json file
src directory containing index.js file

Dockerfile with following configuration
Vim Dockerfile
FROM node:15-alpine as prod
ARG PORT=8000
ENV PORT=$PORT
WORKDIR app
copy src src
copy package.json .
RUN npm install --only=prod
EXPOSE $PORT
CMD npm run start:prod
FROM prod as dev
RUN npm install --only=dev
CMD npm start


docker-compose.yml file with following things
version: "2.3.3" --> define the version of docker compose
services:
  my-app:
    image: my_node_app:${MY_ENV}
    ports:
      - "8010:${MY_PORT}"
    volumes:
      - ./src:/app/src
    environment:
      PORT: ${MY_PORT}

each tag will use two spacebar to place the values in side.

# structure of above yml file
version of docker compose
services: here we define how many container or apps we want to run, anything defined inside services will be after pressing two spacbar
  my_app: this is the tag or name of container
    image: name of image with its tag from which we want to create container
    ports: host and container ports are define here. 
    volumes: bind_mount host:container path is defined
    environment: here we need to define the container port in PORT argument

variables are defined in yml file in {} brackets like ${MY_PORT}

I used two arguments in above docker-compose.yml file, one is My_ENV and One is MY_PORT
MY_ENV is the tag of my image my_node_app

we have to define the above arguments in a .env file
vim .env
