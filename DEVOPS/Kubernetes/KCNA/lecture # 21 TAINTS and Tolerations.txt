Taints & Tolerations

Taints:

What: Taints are like notes you put on a node in a k8s cluster, saying ‘handle with care’ or ‘Special node’

Purpose: They are used to mark nodes to influence pod scheduling.

Usage: taints ensure that only pods with matching tolerations (preference) can be scheduled on that node. 

Tolerations:

What: Tolerations are like preferences that pods (applications) have regarding taints on nodes.

Purpose: They allow pods to tolerate (accept) node with specific taints, enabling them to run on nodes marked with those taints.

Usage: Tolerations help pods ignore the “Spicy” note on a node (snack) if they are okay with it.

TAINTS ARE SET ON NODES AND TOLERATIONS ARE SET ON PODS
