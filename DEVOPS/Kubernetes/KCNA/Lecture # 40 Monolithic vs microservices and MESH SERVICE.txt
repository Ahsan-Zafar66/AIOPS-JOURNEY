Service Mesh:
Ab microservices hain, har service apna kam krti hai.
Likin aik application kafi microservices ko jor kr bnti hai.
Application ki functionality ky liye important hai ky sab miucroservices apas mn bt karein

Ab ya to ham hr microservice ky code mn changes karein ky wo dsri microservice sy communicate karay.
Yahan ati hai service mesh:
Service mesh is a dedicated and configurable infrastructure layer that handles the communication between services without having to change the code in a microservice architecture.
ab microservice ki communication ham service mesh sy krty hain. jis sy hamein microservice ky code mn changings nhi krni parein gin.
