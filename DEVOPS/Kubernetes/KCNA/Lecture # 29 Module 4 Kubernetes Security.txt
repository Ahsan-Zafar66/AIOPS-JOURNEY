2) Attribute Based Acess Control (ABAC)
ABAC allows administrators define access policies on attributes associated with users or processes.
Jo admin ny define kiya ho ga usi ky hisab sy access mily ga
policies are written using attributes like usernames, user groups or other metadata.

Specifying access polices based on user attributes, providing a flexible authorization system



3) RBAC Role Base Access Control  (RBAC)
It is fundamental and widely used authorization mechanism in k8s.
RBAC defines roles and role bindings, allowing fine-grained control over what actions users or components can perform
we make groups, like this group can create, view or delete
another group only can view cannot delete nor create. 
We attach user to these groups and they get access depending upon their roles
