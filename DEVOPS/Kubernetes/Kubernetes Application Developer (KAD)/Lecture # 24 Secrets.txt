Kubernetes are similar like configmaps but are different

Secrets are not Encrypted ONLY ENCODED

Secrets are used for sensitive information.

# example of creating a secret through imperative command
kubectl create secret generic db-secret --from-literal=DB_Host=mysql-service --from-literal=DB_User=root --from-literal=DB_Password=password123

# creating above secret db-secret from yam file
apiVersion: v1
kind: Secret
metadata:
  name: db-secret
data:
  DB_Host: mysql-service
  DB_User: root
  DB_Password: password123


# creating secret
kubectl apply -f secret.yml


# using secret env variables in webapp that require environment variables
apiVersion: v1
kind: Pod
metadata:
  name: webapp-pod
  labels:
    app: webapp
spec:
  containers:
  - name webapp-container
    image: kodekloud/simple-webapp-mysql
    envFrom:
    - secretRef:
        name: db-secret

# in above pod the image used needs the env variables crucial for its working, we define those variables in a secret and now linking secret with pod, telling pod to get variables needed form this secret file



For more details check secret directory in ubuntu kubernetes.
