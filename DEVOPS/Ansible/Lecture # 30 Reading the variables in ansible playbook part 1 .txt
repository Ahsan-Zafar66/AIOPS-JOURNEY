now we will tak input from user which package to target and what to do with that package present/absent/latest

sudo vim user_input


---
- name: this yml file takes input fom user which package to target and what to do
  hosts: centos
  become: yes
  vars_prompt:
    name: "package_name"
    prompt: "Enter the name of package"
    private: no
     
    name: "package_state"
    prompt: "Enter the state present/absent/latest"
    private: no

  tasks:
    name: Now doing what the user wants
    yum:
      name: "{{package_name}}"
      state: "{{package_state}}"
