# how to register node
run the following command on the node machine mentioning the XPUB binding and XSUB binding
java -jar selenium-server-4.6.0.jar node --publish-events tcp://192.168.56.1:4442 --subscribe-events tcp://192.168.56.1:4443


after running above command you will see output and look for ip address of node
http://192.168.56.1:5555



My hub and node machine is same, if you have hub and node on different machines then you need to do following things in node machine
1. You need to download and upload selenium-server-4.6.0.jar file at your node location
2. You need to download and stored drivers in same location
3. you need to copy your python selenium project to your node machine
4. You need to install python package and python at node machine via bulk command


# how to install all packages of python of you hub machine into node machine
# run following command in hub machine
pip freeze > libraries.txt

# now copy this file in node machine in directry where selenium grid and other things ar epresent
pip install -r libraries.txt

above command will install all the libraries mentioned in libraries.txt file
