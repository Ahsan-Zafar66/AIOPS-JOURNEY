Selenium Grid:
It is a tool to do testing on multiple things at once or parallely,
these things can be different browsers at the same time, multiple virtual machines where you want to do testing at once, or different OS


Selenium Grid can be used to execute 
same or different test scripts on
multiple platforms and browsers
concurrently so as to achieve distributed test execution.

It allows running test cases in parallel
thereby saving test execution time.
It allows multi-browser testing.
It allows multi-OS testing.
It allows multi-platform testing (desktop, mobile).


Selenim Components:
Client where you write code or run
Hub which is a control node, where you register you machines, ou browsers
Nodes: these are machines, browsers where the code is executed

So, flow is
client --> hub --> nodes
