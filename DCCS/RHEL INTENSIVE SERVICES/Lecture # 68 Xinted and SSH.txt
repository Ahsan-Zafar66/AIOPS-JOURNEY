Xinetd:
it is a service in which there are samll base services. It is a stand alone services that controls other small services.

which controls multiple child services

xinet based services are telnet, tftp, nrpe, amanda

so if you start these services separately thesde are stand alone and are loaded in RAM, suppose you start telnet, it is loaded in RAM but use of telnet is very little, like this suppose you loaded amanda, it's use is little it is also loaded in rAM, so in the mean time load on RAM increases.
So, to deal with this thing they combined such services inside xinted, when you call telnet xinted get's loaded in RAM start telnet when it's job is finished it removes it from RAm, so in this case load on RAM does not increase

xinetd now loads these services when someone calls for them and when their job is finished it removes them from RAM, so RAM loaded is reduced a lot because services are not running in RAM constantly they only run when they are required and removed when their job is finished.
