How to create a s3 bucket and make content publically accessible?
Step # 1
Create a s3 bucket with a unique name

Step # 2
Upload the object in the bucket you want to make publically available

Step # 3
Make the object public

Step # 4
turn off the bucket BLOCK PUBLIC access option

Step # 5
copy the url of the object and now you can access it publically
