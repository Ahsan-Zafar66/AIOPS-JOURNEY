LAND DNS:
DNS that resolves our local domains such as i have a page sysops.com. I don't want my dns to go out looking for it;s ip when my client calls. I want it to have it and resolve it locally

creating a local zone and resolving local server in dns

# open named.conf file in chroot/etc

zone "sysops.local" {
type master;
file "var/named/sysops.db";
};

resolving local domain sysops.com


# now e have to make data base file in directory
cd /var/named/chroot/var/named/

# making .db file
touch sysops.db

# after creating sysops.db in the /var/named/chroot/var/named/ directory we need to copy zone script from a file
cat /usr/share/doc/bind-version/sample/var/named/named.localhost > /var/named/chroot/var/named/sysops.db 

# now open this file
vi sysops.db

# write this in file at last

sysops.local IN A 4.4.4.4 --> sysops.local is my domain and zone name

# you can also write the above line as
@ IN A 4.4.4.4

# OR
portal.sysops.local IN A 6.6.6.6 --> portal is subdomain

# OR
mail.sysops.local IN A 7.7.7.7 --> mail is subdomain

# now restart the named-chroot
systemctl restart named-chroot
