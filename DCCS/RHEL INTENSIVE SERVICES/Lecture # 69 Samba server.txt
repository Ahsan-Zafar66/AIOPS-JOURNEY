SAMBA:
It is a file server.

It is useful for file sharing.
It works from linux to linux and linux to windows

SAMBA asks for username and password.

NFS do not ask for username and password.

HOW SAMBA(smb) WORKS?
peer to peer access.

domain controler is for centralized authentication

samba makes a workgroup in its machine

samba send nmb to windows and nmb shares folders samba shows

windows communicate with nmb, windows think it is my brother it does not know that behinf the screen samba is working

nfs does not have nmb that is why we cannot share nfs with windows.

samba version4 can be used as active directory

samba is 90% replacement of active directory
