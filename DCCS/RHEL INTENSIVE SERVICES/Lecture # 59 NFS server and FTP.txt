every service have a config file, changing config file changes the binary file in real time when it loads in RAM, we cannot directly edit binary file.
BEST PRACTICE: when you change a config file of a service take it's backup so you can always go back

# loaction of config file of vsftpd
cat /etc/vsftpd/vsftpd.conf

# taking backup
cp /etc/vsftpd/vsftpd.conf /etc/vsftpd/vsftpd.conf.bak -->.bak backup

# now open file and look for Allow Anonymous FTP and change it to NO if it is yes
vi /etc/vsftpd/vsftpd.conf

anonymous_enable=YES ---> change to NO --> anonymous=NO

# restart service after making changes
after changing configuration file we need to restart the service
systemctl restart vsftpd

we restart because when we start the service it';s binary file is loaded in RAM and before loading it refers to config file to see the parameters.
We make change while service is running, so we need to restart t so when binary file is loaed in RAM it refers now to the modified config file and our changes operate.

CHROOT JAILED USERS:

One ftp problem is after connection you can access complete server like all files all directories which is not good from security perspective
So, what we can do if we give someone access to ftp we only give access to a particular directory not complete OS

we can enable chroot which means we enter a directory and a client, that client will have access to that directory ONLY it cannot go out
# go to follwoign file
vi /etc/vsftpd/vsftpd.conf

# look for chroot_user=YES and uncomment the tag line

# now restart the vsftpd service but remember restart is not a good option in production servers as restarting a service breaks connection with all the clients
# In production server we only reload the driver through reload command
systemctl reload vsftpd

Step # 1 uncomment chroot label /etc/vsftpd/vsftpd.conf
chroot_user=YES --> uncomment this line

Step # make a user and set it's password
# make a userftp
useradd ftpuser

# set user password
passwd ftpuser

Step # 3 make a directory in the user
# make a directory in ftp
mkdir /home/ftpuser/ftp_dir


Step # 4 change the home directory permission of the user created to root make the owner root of the home directory of new user
# change permissions of ftp to root
chown root:root /home/ftpuser --> now the owner of this ftpuser home directory is roor


Step # 5
# give permission to home directory of newly created user after making the root owner
chmod 755 /home/ftpuser

Step # 6
# give the directory ownership to the user which we created  
chown ftpuser:ftpuser /home/ftpuser/ftp_dir

# now you can login using ftp myserver_name and can use the jailed user
