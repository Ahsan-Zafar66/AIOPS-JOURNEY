After setting hosts in both server_machine and client_machine and making entry of both machines in each of the machine and after validating through ping command we can cross ping machines we can configure NFS now.


# now let's make a directory in server which we will share with client machine
mkdir /home/firstsharing --> firstsharing we are making in the machine that we want to act as a server.

# now enable rpcbind and nfs-utils (cent os 6 and 7) or nfs-server (centos 8 or 9) by the folowing commands in both machines
# commands for cent 6 and 7
systemctl enable nfs-utils --> cent os 6 or 7
systemctl enable rpcbind

# commands for centos 8 and 9
systemctl enable nfs-server --> cent os 8 or 9
systemctl enable rpcbind


nfs is hosted on port number "2049"

# command to check if 2049 port is listening
netstat -tulnp | grep 2049

# another command
ss -tulnp | grep 2049


-----Server machine Next steps--------
# NFS has a major file /etc/exports, in which we need to make entry for the folder which is to be shared
# iwant to share a folder suppose
/home/ahsan/firstshare

# entry in /etc/exports
/home/ahsan/firstshare *(sync) --> entry of a folder you want to share

# after making an entry we neet to export the shared folder into RAM
# command to export files
exportfs -rv

# command to validate if export is successful 
exportfs -v

-==============================

-----Client Machine Next steps----------

# now first check what has been shared with you by the server
showmount -e myserver.ahsan--> myserver.ahsan is my server name

# stop the server machine firewall now go to server machine and turn off firewall because client will access what has been shared by server
# checking status of firewall on SERVER machine
firewall-cmd --state

# stop firewall
systemctl stop firewalld

# now you can see the filename you shared from server into your client
# now you need to mount this file on a directory in client
# making a directory in client
mkdir /home/ahsan/client_host

# mounting the firstsharing directory from server onto client_host directory in client
mount myserver.ahsan:/home/ahsan/firstsharing /home/ahsan/client_host

# now run df -h command to see the mounted folder
df -h


# now create some file in firstsharing directory on server and check if you see the same file and content on your client. 
# if everything went fine then you must be able to see what you make change in server in client in the client_host directory where you mounted the server firstsharing directory

# making persistent the mounting of firstsharing directory from server on client_host directory in client make an entry in /etc/fstab file
# example
myserver.ahsan:/home/ahsan/firstsharing /home/ahsan/client_host nfs defaults 0 0

myserver.ahsan:/home/ahsan/firstsharing --> directory path of server

/home/ahsan/client_host ---> directory of client on which you want to mount directory of server

nfs --> file system


# after making an entry run command
mount -a


NOTE: if you get any problem in future problem is always in server, client does not have any probelm
What ever you write in server it will be shown in client but you cannot write anything from client, if you want to write you need to give permission to client to write (making new files)

# allowing client for read and write
# got to server machine and open the file
vi /etc/exports

# path of file
/home/ahsan/firstsharing *(sync) it was written initially now change it to --> /home/ahsan/firstsharing *(sync,rw)

# now reload the exports file
exportfs -r

# check file uploaded again
exportfs -v


after doing above steps we need to check firstsharing directory permissions, what permissions it has, if it has read only then you still can;t write anything in it from client. So, you need to give firstsharing read and write permissions.

# Client privileges to server directory
To enter directory from client you need read permission only for the firstsharing directory in server machine.
To read the files of the directory you need execute permission for the firstshring directory in server machine means that you must give firstsharing directory execute permission in server
To create new files you need write permission

now client can create files in the shared directory
