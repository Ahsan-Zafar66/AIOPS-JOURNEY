RUNLEVELS

there are 7 starting from 0 and ending at 6

0 = Halt

6 = Reboot

1 = Single User Mode (safemode)

2 = Multiuser

3 = Full multiuser mode

4 = Unused

5 = Graphical Interface

3 = Terminal Only Interface

==========================================
For runlevel 1 no password is required, it is a single user password.

How will you recovr a forgotten root password?

We will go to runlevel1 means single user mode and reset the password

Press any key to interrupt the boot session

Press a to enter the kernel setting on the reboot screeen


rhgb quiet will be written, remove anything written in front of it

write 1

rhgb quiet 1 and then press enter

You will enter level 1

now set the new password for root

passwd root


you have recovered the root password now.
