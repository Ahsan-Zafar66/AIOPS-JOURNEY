directory permission

if a user has read permission he can read the directories present in that directory

if a user has write permission he can create new directories in that directory and read the content of the directory. If he does not have then he cannot create a nw directory or a file in that directory

if you have execute permission you can enter the folder, if you do not have execute permission you cannot even enter the directory.
