RSYNC:
it is a very powerfool tool for backups.

suppose you have machine 1 and machine 2. In machine 1 you have ahsan and ahmed two files.
Now you create backup of data of machine 1 into machine 2 using rsync. First time it copies everything as machine2 does not have any previous record of this data.
Now, if you run rysnc again for data present in machine 1, rsync will first check the data of machine 1 and machine 2, is there any difference, if there is difference then it will only add the data which is not already present in machine 2. If the data is same then it will not create the backup again it is smart.
