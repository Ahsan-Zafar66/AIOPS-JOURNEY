GZIP:
Gzip does not create a new zip file, it converts the file to a .gz format unlinke zip, zip creates a new file which is compressed the file that is compressed is also available
Gzip is bit fast but give low compression, bzip2 is a bit slow but gives high compression

# file size is not big than use gzip

gunzip file.gz --> to unzip the file compresses through gzip

# to zip all file sin a directory but each file separately

# to unzip all the files
gunzip *


# if file size is very big and you want to compress file to a greater extent use bzip2

-j = do not include the path, if you don't use -j it will also zip the path structure not the files only

Yes, we can but it is not good, the compression stops after a certain point. Fil won't be compressed anymore.

TAR: 

TAR is the native tool of linux. zip is third party

TAR, Tape archive

TAR only archives, it does not do compression

syntax

tar flag filename.tar filestoarchive

tar -cvf mytar.tar * --> archive all the files of the prresent directory (*) into file mytar.tar
c = create, v=verbose, f=file

tar -tvf mytar.tar --> it will only show the files present in mytar.tar
t =list, v=verbose, f= file

# extracting the zip file
tar -xvf mytar.tar 
x = extract, v= verbose, f=file

# we can use gzip and zip after tar to compress the files

# tar + compression with gzip
tar -zcvf myfile.tar.gz ahsan.txt ---> adding z with cvf will compress the file after archiving with gzip

tar -jcvf myfile.tar.bz ahsan.txt --> adding j with cvf will compress the file after archiving it wit bzip2

# to extract the files now
tar -zxvf myfile.tar.gz 

# extracting file to a specified directory
tar -zxvf myfile.tar.gz -C myzip/

# to extract bzip file
tar -jxvf myfile.tar.bz
