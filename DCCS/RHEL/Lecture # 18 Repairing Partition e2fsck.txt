# autorepairing all partitions when my machine reboots

6th field meaning in fstab file
0 --> off
1 --> on


suppose if 6th field for a partition is 0, it means no 22fsck check wwhen machine reboots

for paritions where 6th field is not 0, e2fsck run in order starting from partition given 1, it will run first, then partition given number 2 it will run second. If two partitions given same number such as 2 then they will both be checked together by e2fsck. If a prtition is given number 3 it will be cleaned after partitions given number 1 and 2


5th and sixth field in fstab file are interdependednt, if 5th field is on also turn on 6th field or off then also turn off 6th field (0 off, 1 on)

if you want to see e2fsck when system reboots, look for section "Checking Filesystem" when machine starts
