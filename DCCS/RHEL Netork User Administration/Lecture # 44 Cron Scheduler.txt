what is cron?
cron is a task scheduler. cron runs as a service.

# to check cron
systemctl status crond


# how we sart a service
service service_name start

# example
service docker start

# check service status
service service_name status

# example
service docker status

# restarting service
service docker restart


# stopping service
service docker stop

How to schedule jobs through cron?

crontab -e --> crontab is set for current user and it opens a file 

# for specific user
crontab -u ahmed -e --> setting cron tab for user ahmed

# in the first line of file write
* * * * *  touch scripts.sh --> * are schedule and after stars whatever is written is job

first * = Minutes
second * = Hours
third * = date
fourth * month
fifth * = day of week (monday =1, sunday = 7)

# schedule for Friday 9:30 AM
30 9 * * 5

# schedule for 13th of every month 7:30 PM
30 19 13 * *

# schedule for every new year
00 00 01 01 *

# schedule that the job shoudl run all days except saturday
* * * * 1-5,7 ---> 6 is not included


USE CRONTAB.GURU website to convert your schedules into cron language


* * * * * touch scripts.sh --> five stars fro system but 6 should be for cloud 

the first * is for minutes and second is for hours

15 2 * * * touch scripts.sh --> always at 2:15 am create a file scrits.sh. The other three stars are for always like daily


# to see the jobs scheduled
crontab -l --> list the jobs that are scheduled

What is anacrontab?
Job left by cron is executed by anacrontab

TYPEs of scheduler:
there are three
1.cron
2. anacron (jobs not executed by cron due to system switch off is done by anacron)
3. at scheduler (used only for one time job)
