# adding an ipadress on a network port
ifconfig enp0s3:1 10.0.2.17 netmask 255.255.255.0 --> it will add a new ip address 10.0.2.17 on network enp0s3 and we can add upto 256 networks on one network card, enp0s3 is a driver and we can assign 256 ip address on this network card driver like enp0s3:1, enp0s3:2, enp0s3:256.


enp0s3 --> main network driver, 256 ip can be made
