How YUM Works?
1) yum install docker
2) cd /etc/yum.repos.d --> when we run the command 1) than yum go in this directory and load the repo file
3) refer all .repo file and load it
4) it thne checks baseurl/mirrorlist tag under main tag
5) then it connects to repository server with fastest mirror/url with the help of http or ftp protocol
6) after connecting to the repo server it will check the package in the inventory of the server which is in xml format e.g repomd.xml, if it is present it will download the required package
7) download in local machine -- with curl & store .rpm in /var/cache/yum ..
8) rpm -ivh <pkg.rpm> install
9) it will remove the .rpm pkg after installing the software
