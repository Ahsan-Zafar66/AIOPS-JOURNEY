File System Hierarchy

# finding all files made by user ahsanzafar
find / -user ahsanzafar

# finding all text files
find / -name "*.txt"

# running multiple commands with find
find /etc -user ahsanzafar -exec rm -i {} \;

find /etc -user ahsanzafar --> find any file made by user ahsan zafar

-exec --> it tells that find command is ended and another command is starting

rm -i --> remove interactively like ask by yes or no

{} \--> symbols regular expresion

; --> it tells that command has ended




# another find statement
find /home -perm 777 --> bring all the files that have all permissions


# find all files with root user in the mentioned directory and change user to ahsan
find /home/ahsanzafar/Downloads -user root -exec chown ahsanzafar {} \;

# find all files with the root and give all permissions to all files
find /home/ahsanzafar/Downloads -user root -exec chmod 777 {} \;



NOTE:
{} \; --> there should be a space between {} and \
