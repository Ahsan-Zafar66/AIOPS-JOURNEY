What is kernel?
if you go in /boot directory and run ls command to list the files,
You will see a file vmliz_x86_64 (green color), it is the kernel file.
kernel file is binary
kernel contains functions and it is the heart of sysystem.
It is scheduler of programs, support drivers, information of programs


Suppose we have a car, car is OS and engine is kernel. Engine has information like how many gears, how much speed. Everything that runs depends on engine.
so, kernel controls everything in an OS.

drivers are not located in kernel, kernel control the drivers does not contain them

drivers are .ko --> kernel object
klm --> kernel loadable module
lkm--> lodable kernel module

How to remove a driver from RAM?
# command to remove a driver
rmmod driver_name


# adding driver back
modprobe driver_name

if  adriver is rmeoved by rmmod command it is loaded back after rebooting system because it only removes driver from RAM
