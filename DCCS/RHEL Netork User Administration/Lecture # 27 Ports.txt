Telnet:
Telnet is another tool to check the ports.

# syntax
telnet machine_ip port_number

telnet 10.0.2.15 80 --> if port 80 is open telnet wil make connection. "^]" enter it to get out.

# if you want to check another machine port
telnet other_machine_ip port_number

telnet 10.0.2.0 80 --> check connection of port 80 on machine having ip address 10.0.2.0

================

nc or netcat is another tool to check ports

nc 10.0.2.15 80 --> if prompt does not come then port is open, if prompt comes then port is NOT open

Server Machine Relation:
Suppose  a number of machines are connected to a server, now you want to check which machine is connected with a server through which port.
the command to check this is known as netstat

netstat -a --> it shows details of machines using the ports and connection type

netstat -an

netstat -tulnp --> it shows you port of process, pid as well, state, foreign addresss


Ping:
ping command is used to check network latency, if other machine is available.

ping -c 6 10.0.2.0 --> send 6 packets only to 10.0.2.0


ping -c 6 -s 1064 10.0.2.0 --> send 6 packets pf 1064 bytes size to machine 10.0.2.0



# to send ping through a desired gate (netowk card driver)
ping -I enp0s3 10.0.2.0

ping does not connect with any session. It does not establish a connection, so it does not have any port. Ping uses ICMP protocol

ping works in transport layer (layer 4).

traceroute:
traceroute is another tool like ping.

When we connect to goole through internet there is a route by which we reach google, and this route has routers that transfers the packet from our computer to google. Packet moving from one router to the other is known as hops. 
traceroute tells us about the journey of a packet. If we cannot connect somewhere, we can see at which route packet is failing to get transfered to next router with the help of traceroute

# check the route of google.com, how many hops a packet takes, how fast the packet reaches
traceroute google.com
