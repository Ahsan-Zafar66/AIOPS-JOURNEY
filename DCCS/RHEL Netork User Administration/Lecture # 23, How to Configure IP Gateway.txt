WHAT IS GATEWAY AND HOW TO CONFIGURE IT?
If two machines, machine1 and machine2 have a switch and they are connected with a same network then they don't need a gateway and router.
Same network ip example, machine1 ip 192.168.1.100 machine2 ip 192.168.1.103,
192.168.1.0 to 192.168.1.255 --> same netwoek ip addresses. 192.168.1 this is network and after one 0-255 any number can be given and machines with such ips are considered to have same network.
192.168.1 --> network address, 
192.168.1.0 --> 0 is ip address

in 192.168.1.0 where,
1. --> network ip
0. --> broadcast ip


# two machines which are not on same network they cannot interact without  a router and gateway
machine1 --> 192.168.3.10
machine2 --> 192.168.1.103 

if you see closely their network ips are different one has 192.168.3 and one has 192.168.1

Now, for two machines having different networks we need a router

Router helps to communicate between machine having different networks

we need a gateway to access one machine from other if they have different networks. Gateway is router one side ip


route -n --> to see networks, their ip, thir driver, gateway

route add default gw gateway_adress --> command to set gateway, ask gateway from network providers

after setting gateway, to make it permanent make changes in the ifcfg-drivername file.

reload the file
