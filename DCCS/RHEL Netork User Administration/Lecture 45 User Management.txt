# /etc/passwd file
there are 7 fields in this file

#example
thetest:x:1012:1013::/home/the test:/bin/bash

: --> separator of fields

1 --> thetest= username
2 --> x= passwrd in shadow file
3 --> 1012= uid
4 --> 1013=gid
5 --> :: = gecos finger info
6 --> /home/thetest= home directory
7 --> /bin/bash = shell


if you comment out a user in /etc/passwd file it will not be available

SHADOW FILE:
cat /etc/shadow

there are 9 fields in shadow file, passwd had 7 fields
: --> means separation
1st field = username
2nd field = encrypted password file
third field = password last changed
fourth field = days before your password is not changed, if you write 20 user won;t be able to change password until 20 days
fifth days = change password on mentioned day
sixth days = days before which user recieves an expiration warning of password. Suppose 10 is written so user will get a warning of password expiration before 10 days. 
seventh field = days after which password should expire
eight field = account deactivation days.
ninth field = reserved field
