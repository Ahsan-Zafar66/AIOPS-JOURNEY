the following piece of code will check the meory usage of /dev/sda3 if it is greater than 50 than it will zip the practical4.sh file and will replace it with a space in it. theoriginal data is stored in a zip file whih can be used later
#!/bin/bash


time=$(date +%d-%m-%y-%H) # just getting day,month,year and hour

# getting status of memeory
status=$(df -h | grep /dev/sda3 | sed 's/\%//g' | awk '{print $5}')

# printing status
echo $status


# chekcing if status les than or equal to 50
if [[ $status -le 50 ]]
then
        echo "Status if good only $status used"

else
	# entering the directory
        cd /etc/bash/practical_bash
        echo "Entered in directory succesful"
        
	# archiving the practical4.sh file
	tar cvf - practical4.sh -c > /etc/bash/practical_bash/auth.log-$time.tgz
        
	# replacing the content in the file with a space
	echo " " > practical4.sh
        
	# printing the success message
	echo "var log has been archive"
fi

above code is just an automation of things if memory usage is more we archived the file which can be unzipped using following command

tar -xvf auth.log-23-07-24-18.tgz

it will contain the practical4.sh file.
