addition()
{
	first_num=$1
	second_num=$2
	answer=$((first_num + second_num))
	echo "The sum of $first_num and $second_num is: $answer"
}

first_number=10
second_number=200

addition first_number second_number

a=300
b=500

addition a b

===========================
In above function we define variable first_num and second_num and set $1 and $2 in them, it means when we call function first value passed will be stored in first_num and second number passed will be stored in second_num.
Then i am defining the values of these argumetns before calling function, like first_number is 100 and second_number is 200
then i am using the function with a and b, so this function will sum two numbers in whatever way they are passed either directly while calling the function or passing the variables in them.
