name=(ahsan zafar) -->array

echo $name --> it will show only data before a space. For example it will show only ahsan not zafar

echo ${name[*]} --> calling all elements of array. It will show both ahsan and zafar

echo ${name[1]} --> indexin garray to get zafar which is at 1 index

echo ${name[*]:1:3} --> bring info from 1 to 3 index.

echo ${#name[*]} --> total values in array.


echo ${!name[@]} --> to find the indexing of variables

age=( 24 years old ) ---> array

profession=( pharmacist and data scientist) --> array


desc=${name[*]}${age[*]}${profession[*]} --> combing 3 arrays into a variable

echo $desc --> showing all arrays value

cmd=( $(nginx -v) ) --> storing command in an array

key-value pair in bash

declare -A abc

abc=([name]=ahsan [age]=24 [12]=34 [14]=50)

echo ${abc[*]} --> selecting all values

echo ${!abc[*]} --> index or keys

echo ${#abc[*]} --> counting values

echo ${abc[name]} --> selecting a value by key


when you don;t use declare -A abc

then you cannot specify string key value pairs, such array are simple and only work for intergers

test=([1]=10  [2]=20) --> it will work for both key and values

but

test=([name]=ahsan [1]=10) --> this array will not work.
